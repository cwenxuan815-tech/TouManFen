# 反馈数据边界与文案

> 状态：2026-10-22；B4 已实现，F8 已接入；本文件与代码、API 文案保持一致。

## 1. 数据边界

- 表：`feedback`，与 B7 的 `vote`/`vote_item`/`arena_*` 共用 `serving/run/tmf.db`（`TMF_DB_PATH` 可覆盖），WAL + 事务。
- 字段：`client_id/title/model_id/pred_class/corrected_class/score/created_at/status/source` 等；`status` 本期固定 **pending**。
- 去重：`client_id + trim(title) + model_id`；重复提交返回 409 `FEEDBACK_DUPLICATE`，不重复计数。
- 保留期：30 天；网关启动与 `/feedback/stats` 惰性清理，**只清 feedback**，不删 vote/arena。
- 隐私：不存 IP/UA；日志不记录标题/用户原文。SQLite 中保存公开新闻标题作为审核依据。
- 不训练、不审核后台、不入训练集；反馈不会自动改变模型。

## 2. API 契约

### POST `/api/v1/feedback`
请求：`{client_id,title,model_id,pred_class,corrected_class,score?,source?}`。
成功：
```json
{"request_id":"...","feedback_id":1,"status":"pending","total":1,"message":"反馈已提交，待审核"}
```
错误：`FEEDBACK_INVALID`（400）、`FEEDBACK_DUPLICATE`（409）、`FEEDBACK_STORE_ERROR`/`FEEDBACK_UNAVAILABLE`（503）。

### GET `/api/v1/feedback/stats`
只返回聚合：`total/pending/by_class/by_model/similar_hits/retention_days`；无原始行/标题导出。
`similar_hits` 口径：至少存在一条相似 pending 反馈（3-gram Jaccard ≥0.75）的 pending 行数。

## 3. 相似反馈引用

- 规范化：NFKC → casefold → 仅保留字母数字（含 CJK）→ 3-gram Jaccard；阈值 `>=0.75`。
- 只在单模型 `/classify` 响应附 `human_feedback_hint={corrected_class,status:"pending"}`；并列规则：相似度降序→created_at 最新→feedback_id 最大。
- 不改写 `pred_class`、分数、Top-k；不含反馈原文/ID/client。

## 4. 文案红线

允许：
- 「判错了」「选择正确类别」
- 「反馈已提交，待审核」「已记录，待审核」「已记录过，待审核」

禁止：
- 「已学会」「已重新训练」「模型已更新」「自我进化完成」
- 把人工反馈参考写成替换模型预测；必须保留「未审核」语义
- 承诺反馈会立即改变模型/结果

## 5. 前端行为（F8）

- “判错了”→10 类选择→提交；成功 Toast/计数；重复提示“已记录过”；失败可重试一次；键盘可完成。
- 反馈计数来自真实 `/feedback/stats`；不伪造计数。
- 当前无审核后台；待审核状态不会触发模型更新。
