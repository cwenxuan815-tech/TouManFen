# 演示脚本（6 分钟）

> 适用：隔离本地演示环境（mock worker/本地真实 worker），非生产；现场必须明确数据态。
> 当前限制（2026-10-22）：B8 的 LLM 为 **missing（外部 Provider 未授权）**；F15 cached 自动回退已接线；真实投影/手机验收为模拟。脚本只描述已实现且可演示的能力，遇到限制按本节分支处理。

## 0. 演示前检查（不计入 6 分钟）

| 检查 | 命令/动作 | 通过标准 |
|---|---|---|
| 后端进程 | `stage2.ps1 -Action status` | 网关/worker 自己启动的进程状态正确 |
| 网关存活 | `GET http://127.0.0.1:8000/api/v1/healthz` | 200 |
| 模型就绪 | `GET /api/v1/readyz` | 5 个 worker 状态与预期一致；LLM 是否为 mock 需确认 |
| 前端 | `pnpm dev` 或已构建服务 | `http://127.0.0.1:5173` 可打开 |
| LLM 安全 | 8105 `/metadata` 的 `display_name` | 演示优先 `mock-llm`；真实 Provider 不演示 |
| 网络 | 本机回环/局域网 IP | 若 IP 变更，使用 `127.0.0.1`/当前 LAN IP，并确认防火墙/ CORS |
| 数据态 | 顶部/结果卡 | mock 必须明确说“演示数据”；快照只能标 cached |

> Windows 本机或手机局域网演示优先使用项目根目录的 `启动TMF.bat`。脚本自动检测当前 LAN IPv4，并协调设置前端监听、网关访问地址、CORS 与前端 API 基址；启动后使用脚本输出的地址。本机默认配置仍可通过 `127.0.0.1` 访问。手动启动时才需要自行配置 `TMF_CORS_ORIGINS` 和 `VITE_API_BASE_URL`，详见根目录 README 的“局域网访问”。手机需与电脑网络互通，且电脑防火墙允许访问。

## 1. 十步流程（每步 ≤40 秒，总计约 5 分 40 秒）

| # | 时点 | 操作 | 预期屏幕结果 | 一句话结论 |
|---|---|---|---|---|
| 1 | 0:00–0:20 | 打开首页，介绍分类实验台 | 页面加载后顶部直接显示服务端来源（mock/live；混合/缺失为“来源未确认”+明细）与已就绪模型数 | “这是一个本地新闻标题分类实验台；顶部标识来自服务端 metadata。” |
| 2 | 0:20–0:55 | 输入“北京二手房成交量创年内新高”，停止输入约 250ms，再用 fastText 提交 | 实时建议（fastText）+ 单模型结果：类别、未校准分数/延迟/版本 | “实时提示只是 fastText 的未校准结果，不是最终结论。” |

| 6 | 2:30–3:05 | 点“判错了”→选正确类别→提交 | Toast“反馈已提交，待审核”+计数 | “反馈只进入待审核，不会立即改变模型。” |
| 7 | 3:05–3:35 | 如存在相似 pending 反馈，指出“人工反馈参考（未审核）” | 原预测与参考并列，不替换 | “人工参考是待审核线索，不是新预测。” |

## 2. 三条故障分支（现场转移话术）

### 2.1 mock LLM 离线 → partial → 恢复
- 触发：仅停止本轮自己启动的 mock LLM（不得操作真实 provider/用户 worker），或使用隔离 mock 离线端点。
- 预期：compare 的 LLM 项 `status=error`、summary=`partial`，其它模型仍显示。
- 话术：“大模型当前不可用，这次对比是部分结果，其它模型不受影响；我们只展示真实返回状态。”
- 恢复：重启 mock worker；重新提交对比；2 分钟内恢复。

### 2.2 后端全停 → cached 快照
- 触发：停止本轮自己启动的隔离后端（不操作真实/用户服务）。
- 预期：页面自动读取 `frontend/public/snapshot.json`，显示“离线快照”+生成时间+8 条 cached 内容；顶部徽标为“离线快照”，不显示实时。
- 话术：“后端不可达，这是离线快照（cached），生成于……，不是实时结果；恢复后会退出快照。”
- 恢复：重启隔离后端；刷新或点“重试后端”；页面回到正常来源（分类后显示 mock/live）。

### 2.3 投票不足（<50）
- 触发：竞技场新库/预热状态；不伪造 50 票。
- 预期：显示“预热中”+ Wilson 区间，无 rank。
- 话术：“票数不足 50，只展示区间、不排名；这是人类偏好，不是准确率。”
- 恢复：继续现场投票或使用 **隔离临时 DB** 的演示初态，不写真实库。

### 2.4 后端/网络不可达（IP 变更）
- 触发：隔离 mock 端点不可达或局域网 IP 变化；**不修改本机真实 IP/用户网络**。
- 操作：重新运行 `启动TMF.bat`，使用其输出的当前 LAN 地址；检查手机与电脑网络互通、Windows 防火墙规则及 `healthz`。若是手动启动，再更新 `VITE_API_BASE_URL`/CORS。
- 话术：“地址/网络不通时先回到本机回环地址，现场不伪造服务状态。”
- 若无法恢复：停止演示，说明错误状态；不展示假数据。

## 3. 结束语与红线

- 反馈只能“已提交/已记录，待审核”，不得说“已学会/已训练/模型已更新”。
- 离线基准不得说“实时/线上准确率”；Elo 不得说“准确率/客观排名”。
- mock/cached 必须明确标注；LLM 缺失必须保留 missing，不得用 mock 分数填 B8。
- 当前 D4 未使用真实 LLM/真实投影/真实手机；现场使用真实设备时需按 `docs/现场设备验收清单.md` 补测。
