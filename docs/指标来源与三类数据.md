# 指标来源与三类数据边界

> 状态：2026-10-22 最终收尾；本文件描述**已实现并验证**的口径，不把计划项写成已完成。

## 1. 三类数据必须分列

| 数据类别 | 来源/产物 | 展示位置 | 允许表述 | 禁止表述 |
|---|---|---|---|---|
| 离线评估 | `artifacts/bench/pk_<date>.json`（`meta.data_kind=offline`） | `/api/v1/bench/pk`、PK 榜单页 | 「离线评估（test 集，YYYY-MM-DD，n=…）」 | 「实时准确率」「线上准确率」；把离线指标当运行时表现 |
| 运行时统计 | 网关 `/api/v1/stats`，进程内计数（重启清零） | 运维面板/接口 | 「本次会话统计」；仅统计 `data_source=live` 的模型调用 | 「模型准确率」；把 mock/unknown/cached 计入统计 |
| 人类偏好投票 | SQLite `vote`/`vote_item`，B7 Elo | 竞技场榜 | 「人类偏好（n 票）」「仅供演示参考」 | 「准确率」「客观排名」；把 Elo 当模型能力指标 |
| 演示样例 | mock worker（`display_name=mock-*`）/ 离线快照（`cached`） | 页面徽标/结果卡 | 「演示数据（mock）」「离线快照」 | 任何暗示实时推理的表述；写入运行时统计/基准/反馈数据 |

## 2. 当前 B8 产物的准确口径

- 数据集：`00-data/data/test.txt`，**10,000 条**，10 类；`split=test`；`data_kind=offline`。
- 模型覆盖：RF / fastText / BERT / distill 四个本地模型为 **ok**；**LLM 为 missing**（外部 Provider 未授权，未调用，不能补 mock/估算分数）。
- 指标定义（详见产物 `meta.metric_def`）：
  - `macro_f1`：sklearn `f1_score(average='macro', zero_division=0)`，10 类等权；
  - `accuracy`：top-1 命中率；
  - `confusion_matrix`：10×10，行=true label、列=pred label，行和=该类 support；
  - `avg_latency_ms`：test 前 200 条逐条推理延迟（模型已加载、预处理已预热；不含 HTTP/网络）；
  - `size_bytes`：模型文件字节数；
  - 集成/oracle 为 **派生指标**：加权投票集成权重来自 dev 固定抽样（seed=20261022，每类 200，共 2,000），oracle 为参考上界，**均非独立模型**。
- 产物：[artifacts/bench/pk_2026-10-22.json](../artifacts/bench/pk_2026-10-22.json)；API：`GET /api/v1/bench/pk`。
- 历史对比：RF/BERT/distill 与 `docs/实测指标.md` 的 test 指标一致；fastText 的 macro-F1 与历史 P@1 存在取整/口径差异；延迟与历史批量吞吐不是同一口径，不能直接横比。

## 3. 运行时统计口径

- `/stats.model_calls` 只对 `data_source=live` 的模型调用计数；`mock` / `unknown` / `cached` 不计入。
- 重启网关清零；不写入 SQLite 统计基线；不将演示/快照数据合并进 `/stats`。
- 指标不是「准确率」：没有真实标签时不得从调用次数推导准确率。

## 4. 竞技场数据口径

- `/arena/next` 从 `test.txt` 抽样并保留真实标签，但投票前不返回模型身份；投票后揭晓 selected 模型。
- Elo/Wilson 只表达**人类偏好强度与不确定性**，票数 <50 时 `warming_up`、无 rank；不得称为准确率或客观排名。
- 演示种子只使用隔离临时 DB；演示票/反馈不得进入生产统计或真实反馈数据。

## 5. 演示/快照边界

- 运行时 live/mock 由 worker `/metadata.display_name` 判定（`mock-` 前缀=mock，否则=live；无法判定=unknown，**不猜 live**）。
- `frontend/public/snapshot.json` 与 `artifacts/demo/snapshot_<date>.json` 为 `cached`/演示产物；快照包含 `generated_at`、来源引用、LLM missing；不写入运行时统计、反馈或基准。
- F15 页面级自动 cached 回退已接线：后端请求失败自动读取 `frontend/public/snapshot.json`，显示“离线快照”+生成时间；恢复后退出。cached 不进入统计/反馈/基准。
