# 演示三态与数据真实性

> 状态：2026-10-22；B11 后端/快照、F15 页面级 cached 自动回退已实现并完成 D4 验收。

## 1. 三态判定（运行中）

| 状态 | 判定 | UI |
|---|---|---|
| `live` | worker `/metadata.display_name` **不以 `mock-` 开头** | 绿色「实时」 |
| `mock` | `/metadata.display_name` 以 `mock-` 开头（大小写不敏感） | 黄色「演示数据（mock）」 |
| `unknown` | metadata 缺失/请求失败/字段非法 | 灰色「来源未知」；**不得推断 live** |
| `cached` | 仅离线快照/演示快照，不由运行中网关返回 | 灰色「离线快照」 |

实现：`serving/adapters/http_worker.py` 判定并缓存；`data_source` 透传到 `/classify`、`/compare` 每项、SSE `model` 事件。统计只计 `live`，mock/unknown/cached 不计。

## 2. 快照

- B11：`artifacts/demo/snapshot_<date>.json`，`data_source=cached`，含生成时间/B8 引用/LLM missing；通过 B13 meta 校验。
- D2：`frontend/public/snapshot.json`，8 条固定演示标题（正常3/非新闻1/易混1/可纠错1/慢响应1/超长1），`data_source=cached`，含生成时间、B8/B11 引用、LLM missing；不写运行时统计。演示 seed 见 `serving/scripts/demo_seed.py`。
- 快照/演示数据只用于展示，不进入基准、反馈或统计；LLM 缺失保留 `missing`，不得补 mock 分数/预测。

## 3. URL 提示

- `?demo=mock|cached` 只影响提示文案，不改变数据来源、不替换 API 响应、不制造结果；浏览器不能据此把 unknown 标为 live。
- F15 组件/`useDemoState` 已提供显式来源接口与提示接口；演示徽标使用显式数据，不根据 URL/可达性推断。

## 4. 当前实现边界

- B11 后端字段与快照已存在并验证：mock/live/unknown 分支、统计排除、LLM missing。
- F15 页面级 **自动加载 `public/snapshot.json` 并整页 cached 提示已接线**：模型请求失败时自动读取快照，显示“离线快照”+生成时间+8 条 cached cases；恢复后自动退出快照；快照不存在/非法显示明确错误。实现见 `frontend/src/App.vue`/`composables/useDemoState.ts`。
- 启动时 App 主动请求 `GET /api/v1/demo/state`：服务端对全部已启用 worker 探测 metadata；全部 ready 且来源一致才返回 mock/live，混合/缺失/不可用返回 unknown，并附 `worker_sources`。页面首屏即显示服务端确认的 mock/live/unknown，不等待第一次分类；分类/对比结果仍按各自 `data_source` 更新对应结果卡。
- F13 的设备验收为模拟（Edge headless/CDP），不是真实投影/手机/笔记本验收；F15 的断开/恢复也是浏览器模拟。

## 5. 演示使用要求

1. 使用 mock worker 时，现场明确说“这是演示数据，不是实时模型”；
2. 快照只读展示，页面不得出现「实时」；
3. LLM 当前未纳入真实基准（B8 missing），演示中不得展示 LLM 分数/准确率；
4. 不把 mock/cached 投票/反馈写入运行时统计或真实数据。
