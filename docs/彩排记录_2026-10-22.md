## 2. 故障场景

### 2.1 LLM 离线 → partial → 恢复

- 显式勾选 LLM + 选择大模型；隔离 mock LLM 在线 → 5/5 成功（`d4-fault1-online-isolated.json`）。
- 停止本轮 LLM mock worker（14514）→ 提交对比：4 本地成功 + LLM `WORKER_UNAVAILABLE`，summary partial（1,969ms，`d4-fault1-offline-isolated.json`）。
- 重启 mock LLM → 5/5 成功（20,575ms，`d4-fault1-recover-isolated.json`）；恢复墙钟 20.7s，≤2 分钟。
- 网络仅 14520/18084，`bad_network=[]`。

### 2.2 后端全停 → cached → 恢复

- 停止本轮网关 14520，刷新页面：页面实际请求 `http://127.0.0.1:18084/snapshot.json`，徽标 `demo-cached`，显示生成时间 `2026-10-22T07:53:25+08:00`（`d4-fault2-offline-isolated.json`，3,567ms）。
- 重启网关：cached 退出，启动接口恢复 mock（`d4-fault2-recover-isolated.json`，3,521ms）。
- 网络允许 14520/18084，`bad_network=[]`。

### 2.3 地址不可达（隔离）

- 构建 API base `http://127.0.0.1:18996`（未监听），静态 18085；页面加载合法 snapshot → “离线快照”+生成时间；请求仅 18085/18996，`bad_network=[]`。
- 证据：[d4-fault3-unreachable-isolated.json](../artifacts/d4/d4-fault3-unreachable-isolated.json)、`fault3-unreachable-isolated.png`。
- 这是浏览器/网络模拟，不是真实断网/防火墙验收。

### 2.4 Mock 模式完整演示

- **独立第二次完整 10 步**（与正常彩排分开运行）：**10/10 PASS，10,002ms**；mock 标识贯穿页面/结果卡；未写 live 统计/基准；未调用真实 LLM。
